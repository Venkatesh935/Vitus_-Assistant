## 📌 About The Project

**Vitus AI** is a Windows-based voice-controlled laptop assistant developed using Python.

Vitus allows users to interact with their computer using voice commands instead of manually performing every action.

The assistant is designed to understand spoken commands, convert speech into text, identify the user's intent, execute safe computer operations, and respond using text-to-speech.
